# 业务演练

|情景|演练操作|期望受理状态|
|---|---|---|
|条件必填|叶片不填介质|停留在校验阶段，没有受理号|
|类型变更|填后切换类型|清空的字段重新填写，摘要与业务输入一致|
|正常登记|data/handover.json|每个业务键认领一个真实回执|
|未知提交结果|lostResponseOnce=true|无重放时从查询页认领唯一相同内容，不再点击提交；浏览器自动重放产生同键两条记录时暂停交人工，不认领其一|
|提交前退出|在点击前持久化意图后退出|重启先查询，确认不存在才继续登记|
|回执未记账|看到回执后立即退出操作端|恢复认领既有回执，不制造新受理|
|冲突|同键不同内容的已有记录|暂停该项，保留最小人工复核信息|
|多记录|同键两条已有记录|不任意认领其一|
|日志|输入含联系人|执行日志和汇总无联系人明文|

以上情景由 `browser/intake.test.mjs`（浏览器回归，含三个崩溃注入点）与 `test/rpa.test.mjs`（状态机与裁决单元测试）覆盖。
